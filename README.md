# Meridian Library Portal

**Meridian Library** is a polished, reader-facing library portal concept. It brings together an editorial book discovery experience, a broad subject catalog, availability labels, short book summaries, and a built-in book concierge.

## Features

- 60 illustrative titles across literature, speculative fiction, engineering and computing, science, history, art and design, business, young readers, and research reference
- Search across title, author, category, publication year, and summary
- Browse curated subject shelves and filter titles by current availability
- Sort by title, newer editions, or reader favorites
- Open each title for its summary and sample availability
- Save titles to a reading list in the current browser
- Ask the Meridian Concierge about book availability, summaries, or recommendations based on a subject or reading preference
- Responsive layout for desktop and mobile

## Open locally

Open `index.html` in a browser, or open the project folder in VS Code and run `index.html` with Live Server. There is no build step, package manager, or server-side setup required. Keep `index.html`, `styles.css`, `catalog.js`, and `app.js` together in the same folder.

## GitHub Pages

The project is a static website and can be hosted with GitHub Pages:

1. Add the project files to the repository root on the `main` branch.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.

## Demo details

This is a front-end prototype. Availability and copy counts are illustrative. The concierge searches the included catalog using local matching and curated summaries; it is not connected to a generative AI service or live library database. The reader sign-in and membership panels are concept previews. A live service would need secure reader accounts, a shared catalog and circulation API, current inventory data, privacy controls, and an AI provider if generative answers are required.
